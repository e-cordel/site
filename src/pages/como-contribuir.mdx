# Como contribuir

O e-cordel é um projeto colaborativo e precisa de diferentes profissionais para fazê-lo acontecer. Também queremos que seja um espaço de aprendizado e troca de experiências, então não se preocupe se ainda não possui todo o conhecimento: toda ajuda é necessária.

Para mais informações, entre em contato por [contato@ecordel.com.br](mailto:contato@ecordel.com.br).

## Formas de contribuir

### Definição de termos de uso e aspectos legais

O e-cordel pretende disponibilizar gratuitamente o acesso às obras cadastradas. Para isso, precisamos identificar os aspectos legais e direitos autorais necessários para armazenar e distribuir digitalmente as obras.

### Revisão de obras na plataforma

As primeiras obras disponibilizadas são de domínio público. Coletamos cordéis já publicados na internet e, em alguns casos, precisamos revisá-los e ajustar informações. É uma oportunidade de ler cordéis e publicá-los na plataforma.

### Site e mídias digitais

Você pode contribuir ajudando a construir o site e a comunidade nas redes sociais.

### Teste da plataforma

Ajude a testar o aplicativo e as principais funcionalidades para identificar erros e problemas.

### Desenvolvimento da plataforma

O e-cordel é open source. Você pode fazer um fork dos [projetos no GitHub](https://github.com/e-cordel/) e criar um pull request. A melhor abordagem é conversar primeiro com os desenvolvedores atuais para receber orientação nas primeiras tarefas.

## Antes de começar

- Tenha tempo disponível para contribuir com o projeto.
- Conhecimentos básicos de Git são úteis; as contribuições são recebidas por pull request.
- O e-cordel é licenciado sob a Apache License; leia a licença antes de contribuir.
- Sua contribuição será revisada pelos desenvolvedores.

## Como começar

As tarefas estão registradas no [Trello](https://trello.com/b/evgWanzE/e-cordel). Para começar:

1. Entre no [grupo do Discord](https://discord.gg/4BpsgF5TuA), apresente-se no canal **#geral** e diga como pretende contribuir.
2. Uma pessoa responsável pela área dará as primeiras instruções.

Não encontrou uma forma de ajudar? Entre em contato pelo [e-mail](mailto:contato@ecordel.com.br) ou pelo grupo do Discord.
